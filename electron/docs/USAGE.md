# 织声 WeaveVoice 使用指南

> 适用版本 1.0.15 及以上。界面为中文，所有推理在本机显卡完成，不上传云端。

---

## 一、安装

1. 从 [Releases](https://github.com/DAKEZZ52/weavevoice/releases/latest) 下载 5 个文件：
   - `WeaveVoice-Setup-<版本>.exe`
   - `payload.7z.001` ~ `payload.7z.004`
2. 把这 5 个文件放在**同一个文件夹**里，双击安装包。
3. 安装到用户目录（不需要管理员），建议路径保持默认。
4. **首次启动**会自动：
   - 按序拼合 4 个分卷 → 解压运行环境（约 8.6 GB，1 分钟左右）
   - 下载约 5.3 GB 预训练模型（ModelScope 国内源，只下一次）
   - 加载语音服务（15~90 秒，取决于硬盘）

> 首次启动左上角显示「服务启动中…」属正常，**变绿（服务就绪）后**才开始用。

### 系统要求

| 项 | 最低 | 建议 |
|---|---|---|
| 系统 | Windows 10 x64 | Windows 11 |
| 显卡 | NVIDIA 6 GB 显存 | 8 GB 以上 |
| 内存 | 16 GB | 32 GB |
| 磁盘 | 25 GB 可用 | SSD |

## 二、界面速览

```
┌ 侧栏 ────────┐┌ 工作区 ────────────────────────┐┌ 参数 ─┐
│ 音色列表      ││ 文本 / 参考文本 / 波形 / 结果     ││ 语速   │
│ 参考音频列表  ││                                 ││ 步数   │
│ 输出目录/更新 ││                                 ││ [合成] │
└──────────────┘└─────────────────────────────────┘└────────┘
```

顶部标签页：

| 页 | 干什么 |
|---|---|
| **单句** | 一句话合成，带试听与历史 |
| **批量** | 长文自动拆句、逐句合成、失败重试、导出 zip |
| **音频书** | 整本书分章、断点续跑、导出带章节 m4a + SRT 字幕 |
| **翻唱** | 选一首歌，自动分离人声 → RVC 换音色 → 混音（需本机装 RVC） |
| **训练** | 用一段素材微调自己的音色 |
| **设置** | 模型管理、生成记录、外观主题、日志 |

## 三、单句合成（最常用）

1. 左侧选一个**音色**（如 `zhiyu`）
2. 选一段**参考音频**（3~10 秒），右侧填上这段音频里说的原话
   - 参考文本填对，合成质量最好；留空则用「无参考文本模式」，效果略差
3. 中间输入要合成的话（建议一次一句，30 字以内最稳）
4. 右侧调参数（一般不用动）→ 点 **合成语音**（或 `Ctrl + Enter`）
5. 结果可试听、复制路径、打开目录

**参数含义**

| 参数 | 说明 |
|---|---|
| 语速 | 0.6~1.65，默认 1.0 |
| 采样步数 | 4 最快 / 8 推荐 / 16 更稳 / 32 最慢最精细 |
| top_k / top_p / temperature | 随机性，越大越"活"也越容易跑偏 |
| 切分方式 | 单句一般选「不切」 |

---

## 四、批量合成

1. 切到 **批量**，粘贴整段文字
2. 点 **按文本重建队列**：按句号/问号/感叹号拆句，长句再按逗号切到 40 字以内
3. 点 **开始批量合成**，逐句处理：
   - 失败句会标红，可用「只重试未完成」补
   - 完成后可「导出 zip」
4. 输出在 `payload\output\batch_<时间>\`

> 每句会自动换 4 个种子重试；仍然没声音的句子会标为失败（模型对个别句式会吐静音，换个说法通常就好）。

---

## 五、音频书

1. 切到 **音频书**，把整本书粘进去，或点 **导入 txt**
2. 点 **开始生成**：
   - 自动识别「第一章 / 第1章 / Chapter 1 / # 标题」分章
   - 没有标题时按段落每 3000 字切一章（可调）
3. 生成中可以 **停止**；之后在下方 **历史** 里点「展开」→ **继续未完成**，已合成的句子会跳过
4. 完成后自动导出：
   - `<书名>.m4a`：带章节标记，播放器/播客里能跳章
   - `<书名>.srt`：逐句字幕，可直接拖进剪辑软件
   - `chapter_001.wav …`：每章一份 wav

**章节级操作**

- 历史里「展开」可以看到每章状态
- 点某章的 **重做**：只重合成这一章，其余不动，完成后自动重建 m4a 和 srt

**注意**

- 中间文件在 `audiobook_<时间>\parts\`，几万字会有几百 MB，交付后可整个目录删掉
- 字幕时间轴按实际合成时长生成，导入剪辑软件可直接对齐

## 六、翻唱（需要本机安装 RVC）

前置条件：本机有一个含 `.venv` 的 RVC 目录（`assets/weights` 里放 `.pth`，`assets/indices` 放 `.index`）。程序会自动探测，也可用环境变量 `RVC_ROOT` 指定。

1. 切到 **翻唱**，点 **选择音频** 选一首歌
2. 选音色模型和检索索引（列表按最新排序）
3. 勾选「自动分离人声/伴奏」，可选变调
4. 点 **开始转换**，流程：
   - UVR5 分离人声/伴奏（CPU，约 1~3 分钟/首）
   - RVC 转换音色（GPU，约 15 秒/首）
   - 混音 + 响度归一（约 2 秒）
5. 输出 `翻唱_<歌名>_<时间>.wav`

> 转换期间会自动暂停语音合成服务释放显存，结束后自动恢复。

## 七、训练自己的音色

1. 准备 5~30 分钟**干净人声**（无伴奏、无混响、同一人、同一设备）
2. 切到 **训练** → 选择素材文件夹
3. 填实验名（英文/数字），设轮数：
   - SoVITS 8 轮、GPT 15~30 轮，`batch` 6 GB 显存填 1~2
4. 点 **开始处理**：切片 → 语音识别打标 → 文本/BERT → HuBERT → 声纹 → 语义 token
5. 再点 **开始训练**：SoVITS 微调 → GPT 微调
6. 完成后左侧音色列表会出现新音色，可直接用

> 6 GB 显存下，10 分钟素材约 1~2 小时。训练期间不要合成。

## 八、设置页

| 区块 | 作用 |
|---|---|
| 训练好的模型 | 列出所有 SoVITS/GPT 权重，可删除不再用的 |
| 生成记录 | 所有输出音频，可播放/删除，按 翻唱/试听/唱歌/单句 分类 |
| 关于 | 版本、音色数、运行环境路径、**外观主题（暖调/冷调/浅色）**、打开日志 |

**出问题时先看日志**：设置 → 关于 → 打开日志，文件在 `%APPDATA%\weavevoice\logs\`。

## 九、常见问题

**Q：一直卡在「服务启动中」**
A：看日志末尾。常见是显存不足（关掉游戏/其他 GPU 程序）或模型缺失（重装或检查 `payload\GPT_SoVITS\pretrained_models`）。

**Q：合成出来是静音**
A：模型对某些句式会失败。换个说法、加个逗号、或把采样步数调到 16 再试。

**Q：声音不像**
A：参考音频质量决定上限。用同一人、同设备、无噪音、情绪平稳的 5~10 秒；参考文本必须逐字对应。

**Q：能商用吗**
A：软件 MIT。但**音色**取决于素材来源：用自己的声音没问题；用他人声音需要授权，公开发布有法律风险。

**Q：更新怎么装**
A：安装版启动会自动检查更新（支持差分下载）。也可以手动下新安装包覆盖安装，`payload` 会保留。

**Q：磁盘占用太大**
A：`payload` 约 17 GB 是运行环境，删了就得重下；`output` 里的历史音频和 `audiobook_*\parts` 可以清。

## 十、文件都在哪

| 内容 | 位置 |
|---|---|
| 程序 | `%LOCALAPPDATA%\Programs\织声\`（默认） |
| 运行环境 | `<安装目录>\payload\` |
| 输出音频 | `<安装目录>\payload\output\` |
| 音色权重 | `payload\SoVITS_weights_v2Pro\`、`payload\GPT_weights_v2Pro\` |
| 参考音频与配置 | `%APPDATA%\weavevoice\` |
| 日志 | `%APPDATA%\weavevoice\logs\app-日期.log` |
